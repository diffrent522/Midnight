# Midnight

**Midnight — The Best Roblox Utility**

Midnight is an all-in-one Roblox utility for Windows, built with a clean and simple interface. It provides useful tools for managing Roblox, accounts, clients, settings, and more.

![License](https://img.shields.io/badge/license-GNU%20GPL-blue)
![Platform](https://img.shields.io/badge/platform-Windows-lightgrey)
![.NET](https://img.shields.io/badge/.NET-8.0-purple)

## Features

- **Account Manager** — Manage and switch between multiple Roblox accounts.
- **Fast Flags** — Easily manage and configure Roblox Fast Flags.
- **Active Clients** — View and manage currently running Roblox clients.
- **Multi-Instance** — Run multiple Roblox clients simultaneously.
- **Auto Rejoin** — Automatically rejoin games after disconnecting.
- **Server Browser** — Browse and join available Roblox servers.
- **Version Manager** — Manage and use different Roblox versions.
- **Friend Manager** — Manage friends and friend requests.
- **RAM Monitoring** — Monitor resource usage from active Roblox clients.
- **Roblox Utilities** — Access additional tools and settings from one application.
- **Modern UI** — Clean, responsive interface designed for Windows.

## Requirements

- Windows 10 or Windows 11
- .NET 8 Desktop Runtime
- Microsoft Edge WebView2 Runtime

## Installation

1. Download the latest Midnight release.
2. Run the installer or extract the portable version.
3. Launch Midnight.
4. Start using the available utilities.

No source code setup or development environment is required.
